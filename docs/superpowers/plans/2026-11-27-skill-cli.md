# Skill CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run installed multi-file Python Skill CLIs with explicit arguments and safe diagnostics, without changing the existing `run(arguments)` tool.

**Architecture:** Register a separate, side-effecting `skill:run_python_cli` in Windows local chat when loaded or selectable Skills exist. Resolve the entry point inside the loaded Skill, then invoke it in a Python worker under the existing Windows PowerShell/Job Object supervisor. The worker restores normal script-directory imports and CLI argv; the supervisor returns bounded stdout on success and fixed diagnostics on failure.

**Tech Stack:** Python, FastAPI SSE, Windows PowerShell and Job Objects, pytest.
