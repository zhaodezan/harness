# 本地插件库与智能体调试页设计

日期：2026-11-22  
状态：设计已获用户确认，待用户审阅

## 背景与目标

当前 Agent Harness 已有智能体配置页、对话页、MCP Server 管理弹窗、基于本机目录的 Skills 发现，以及运行时工具注册与副作用审批。用户希望将本地扩展能力集中管理，并在配置智能体时同步调试。

本次目标：

1. 在工作区导航中增加“插件库”，集中呈现本地 Agent、Skill、MCP、Tool 四类插件。
2. 暂不接入在线市场；第一阶段仅提供本机配置或加载，并展示已安装项。
3. Skills 改为导入 ZIP 或从已加载 Skills 中选择，不再要求用户在智能体表单填写目录路径。
4. 支持由用户编写 Python 函数或加载本机 `.py` 文件作为自定义 Tool。
5. 每个智能体独立选择启用的 Skills、MCP 工具和自定义 Tools。
6. 智能体配置与调试聊天左右并排；配置自动保存，调试立即使用最新配置。
7. 移除服务商输入/输出 Token 单价配置；保存时清空已有费率设置，历史运行记录保留已计算的费用。

## 用户界面与导航

- 工作区导航增加“插件库”入口，打开插件库页面。
- 插件库提供五个顶层 Tab：**Agent、Skill、MCP、Tool、第三方插件**。当前阶段不显示在线市场内容；Agent/Skill/MCP/Tool 继续提供本地配置或加载及已安装列表。
- **第三方插件** Tab 下提供 **Dify** 与 **DSH** 两个子 Tab；第一阶段仅显示“暂未实现”的占位说明，不提供插件发现、加载、安装、连接或执行功能。
- 工作区侧栏只保留“插件库”作为插件管理入口；移除重复的“工具与连接”侧栏入口，MCP 管理统一在插件库的 MCP Tab。
- **Agent**：复用现有智能体列表、新建和编辑能力；可进入配置页与调试视图。
- **Skill**：展示应用已加载的 Skills；允许导入 ZIP，并查看名称、描述、加载状态及哪些智能体正在使用。
- **MCP**：沿用现有 stdio/HTTP Server 配置、连接/断开、连接前确认和已发现工具列表；管理入口统一放在插件库。
- **Tool**：展示已加载的 Python Tools；提供代码编辑器新建/编辑，也支持选择本机 `.py` 文件导入。
- 智能体配置页使用左右分栏：左侧编辑基本配置与插件选择，右侧调试聊天。窄屏布局可上下堆叠，但两区仍在同一配置页面内。

## 本地插件加载与运行

### Skills

- 用户可选择 ZIP 文件导入；ZIP 解压至应用本机数据目录下的受管理 Skills 存储区。
- 导入 ZIP 最大 10 MB；验证 ZIP 成员路径及内容，拒绝绝对路径、`..` 路径穿越、指向存储区外的链接及不符合预期的目录结构。
- 每个 Skill 必须包含可解析的 `SKILL.md` frontmatter，至少有非空 `name` 与 `description`；无效包应返回可理解错误，不留下半安装目录。
- 导入后在全局已加载列表出现，供每个智能体单独勾选。智能体的运行时仅载入所选 Skills；未选择时不隐式启用全库 Skills。
- 升级时尝试将旧版 `skill_directory` 中有效的 Skills 导入受管理存储区，并把这些名称作为该智能体的已选项，保留原有功能。无法访问或迁移失败时不得清空旧路径或静默丢失能力；在配置页提示迁移失败并保留可恢复信息。

### MCP

- 保留现有本机 stdio 与 HTTP Streamable MCP 连接模型与显式连接确认。
- 插件库中的 MCP 安装/配置是全局登记；智能体配置可单独授权其可调用的已连接 MCP 工具（建议按工具级别选择，而不只是全 Server 全开）。
- 运行时依据当前智能体授权过滤 MCP 工具；未授权的 MCP 工具不得传给模型或执行。
- MCP 连接、发现或调用错误应在插件库/调试侧清晰呈现，不影响未使用该 MCP 的其他智能体。

### Python Tools

- 支持编辑器创建/编辑工具源代码，以及从本机 `.py` 文件加载；加载后的源代码保存在应用本机数据目录，避免依赖原始导入文件路径。
- 第一版每个 Python 模块导出一项 Tool，采用明确的元数据与函数契约：名称、描述、参数 JSON Schema、风险级别，以及 `run(arguments)` 执行函数。兼容同步和异步执行函数。
- 在加载或运行用户代码前明确提示：Python 工具以本机后端进程权限执行，当前版本不提供沙箱隔离；用户只应加载可信代码。加载/更新代码需由用户主动操作，不从在线来源自动执行。
- 加载时验证元数据、名称唯一性、参数 Schema 和执行入口；错误应显示到具体工具且不破坏其他已加载工具。
- 遵循现有运行时风险策略：副作用工具在函数执行前要求用户批准；未获批准不得调用处理函数。
- 每个智能体分别选择可用的本地 Python Tools；运行时执行层和模型可见的工具列表均按该选择过滤。

### Agent 与数据兼容

- Agent Tab 管理现有本地智能体，不引入在线 Agent 包格式。
- 新增智能体级的工具授权数据（Skill 继续使用选中列表；MCP/Tool 使用稳定 ID 或稳定名称，不依赖展示文本）。
- 新建智能体默认不授权任何 MCP/自定义 Tool；升级时为既有智能体初始化其升级前可用的 MCP/Tool 授权，以保留现有行为，且不扩大该智能体原本的可用范围。用户之后可在配置页调整。
- 现有 API、数据库字段与备份/恢复流程应保持兼容；新增授权数据需要包含在导出与恢复中。

## 配置自动保存与调试聊天

- 编辑已有智能体时，字段变化经过短暂防抖后自动 PATCH 保存；界面明确显示“保存中”“已保存”或“保存失败”，失败时保留草稿并允许重试。
- 自动保存需串行化或合并并发更新，避免较早请求晚到覆盖较新编辑；页面离开时应尽量完成待保存更新，无法保存时提示用户。
- 新建向导仍先测试模型连接；连接成功后创建本机智能体并安全保存凭据，随后所有配置改动自动保存。不能因输入中的无效/不完整字段反复创建智能体。
- 调试消息直接使用发送时前端配置表单的最新快照，包括模型、系统提示词、变量、所选 Skills 和所选工具，不因防抖保存仍在途而回退到旧配置。编辑已有智能体时使用已存凭据；新建时使用测试连接后保存的凭据。调试工具调用同样执行风险审批。
- 调试对话本身第一版不持久化；离开配置页后调试消息清空。自动保存只针对智能体配置。
- 新建或编辑页面中移除服务商标价表单项；保存时将费率置空，停止未来运行继续使用旧的费率估算。既有运行日志中已经写入的费用不回算、不删除。

## 错误处理

- ZIP 过大、损坏、结构不合法、重复 Skill 名称、Python 元数据/语法/加载失败、MCP 连接失败、自动保存失败等情况均显示可操作的错误信息。
- 插件安装采用原子化处理：验证成功后再发布到已安装列表；中断或失败不能留下被视为可用的残缺插件。
- 移除正在被智能体引用的插件时阻止删除并说明相关智能体，或要求先解除所有引用；不允许保存悬空引用。
- 自动保存失败时仍允许用户继续编辑和调试，但必须持续显示未保存状态；离开页面前提示风险，避免静默丢失。

## 验收与测试

### 后端

- ZIP 导入验证有效 Skill；拒绝路径穿越、恶意成员路径、无效 frontmatter、重复名和损坏 ZIP；失败后无残留安装项。
- Python Tool 加载验证元数据、Schema、函数入口、名称冲突；执行前检查参数类型和副作用审批；加载失败不影响其他 Tool。
- 智能体运行时只暴露并执行该智能体授权的 Python/MCP 工具；未授权工具被拒绝，即便请求伪造工具名。
- 旧 Agent、旧 Skills 配置、MCP 配置、备份导入/导出能兼容；费率保存后为 null，既有日志费用保持不变。
- 自动保存 API 更新失败可恢复，且并发更新不会用旧值覆盖新值。

### 前端

- 工作区显示插件库入口；插件库含五个顶层 Tab，其中第三方插件 Tab 有 Dify 与 DSH 两个占位子 Tab，两个子页均不提供加载、安装或连接操作；侧栏没有重复的“工具与连接”入口。
- Skills ZIP 导入与已加载 Skills 勾选状态准确反映；MCP Server 可配置、连接、断开并查看发现的工具；Tool 可编辑、导入与管理。
- 配置页左右分栏，调试面板发送内容使用最新草稿配置；窄屏布局可用。
- 编辑字段自动保存并展示状态；网络错误保留草稿并允许重试；新建智能体只创建一次。
- 每个智能体的 Skill/MCP/Tool 选择互相独立。
- 新建和编辑界面不再显示费率输入项；旧运行记录中的费用仍可查看。

## 不在本次范围

- 在线插件市场、账号、远端目录或自动下载更新。
- 任意第三方 Tool 执行沙箱；用户 Python 代码作为可信本地代码运行。
- 调试对话持久化、历史调试会话管理。
- 除 Skills ZIP 与 Python `.py` 文件外的插件包格式。
