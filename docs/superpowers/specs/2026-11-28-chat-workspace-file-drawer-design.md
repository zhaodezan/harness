# 聊天工作区文件抽屉设计

**日期：** 2026-11-28  
**状态：** 已确认并实现（2026-11-28 补充聊天布局与滚动要求）

## 目标

在聊天界面右侧增加当前会话工作区文件抽屉，让用户不离开对话即可浏览、打开、预览和编辑该会话工作目录里的文件。它是聊天内能力，不是一个独立文件管理页面。

## 已确认的产品决策

- 不在左侧导航添加“文件与工作区”入口，也不新增独立文件管理页。
- 只在聊天界面右侧提供文件抽屉入口。
- 抽屉跟随当前会话所选的工作区目录；切换会话或工作区时，文件树和打开文件应对应更新，不能串到上个会话。
- 文件列表支持目录浏览；点击文件后在抽屉内容区打开。
- 允许的文本/代码文件可编辑，采用手动保存。
- 支持多个文件标签页并行打开，标签可关闭。
- 切换文件、关闭标签或关闭抽屉时，如当前文件有未保存修改，提示保存、放弃或取消。
- 不可编辑文件在格式受支持时预览；其他格式仍在列表中显示，并提供文件信息及系统打开/下载方式。
- Docker 沙箱不挂载本机工作目录，因此沙箱模式下抽屉显示“此会话没有可浏览的工作区”，不暴露本机目录。
- 在聊天消息中点击指向当前工作区内文件的链接时，在右侧抽屉打开对应文件；不允许链接跳出当前工作区边界。
- 在聊天消息中点击 HTTP/HTTPS 网页链接时，在右侧抽屉以独立标签打开网页预览。网页禁止嵌入时，给出提示并提供在系统浏览器打开的选项。

## 界面与交互

1. 在聊天页顶部增加“文件”按钮。点击后，聊天内容区域右侧展开抽屉；再次点击或关闭按钮收起。抽屉不覆盖左侧主导航。
2. 抽屉标题区显示当前工作区名称/路径的简要信息及关闭按钮。尚无可用工作区时给出明确空状态。
3. 抽屉主体为可展开的目录/文件树。选择文件后，在右侧内容区打开相应标签；有多个文件时显示多个标签，可切换查看。
4. 文本/代码文件使用轻量编辑区，提供保存、未保存状态及必要的加载/保存错误提示。保存成功后清除脏状态。
5. 常见图片和 PDF 使用内嵌预览；浏览器能安全原生呈现的常见媒体可以预览。未知或不安全的主动内容不在应用内执行，显示类型、大小等信息，并可由用户选择下载/系统打开。
6. 聊天中工作区文件链接在文件标签中打开；HTTP/HTTPS 网页链接在网页标签中打开，保持在同一个右侧抽屉的标签栏中。
7. 网页预览采用隔离的内嵌浏览上下文，不允许网页操控宿主应用、顶层窗口或访问本机文件。只允许 HTTP/HTTPS URL；不支持嵌入（如站点的 CSP 或 X-Frame-Options 禁止）时显示提示，并提供由用户主动选择在系统浏览器打开的回退方式。网页预览请求会直接访问目标网站，页面及其资源可能向该网站披露常规网络请求信息。
8. 文件内容按会话与目录变化隔离。切换会话后关闭旧会话的标签，避免旧内容短暂显示或误保存到新工作区。
9. 桌面端抽屉通过正常布局流扩展聊天主区域，展开后占用真实宽度并缩窄聊天列；不得使用绝对定位覆盖消息或输入区域。窄屏下也不得覆盖对话内容，使用并排宽度或独立占用主内容宽度的布局。
10. 聊天顶部不显示设置/齿轮按钮；左侧账户区的设置按钮保留。
11. 对话消息区域独立滚动，进入会话、切换会话、加载历史和新消息追加后默认滚动到底部；用户阅读较早消息时避免每次流式更新强制抢回滚动位置，用户回到底部后恢复跟随。
12. 抽屉开关不能导致消息区滚动位置异常；切换会话时打开消息区后从底部开始。

## 后端与安全边界

- 新增按会话读取工作区文件树、读取文件、保存文件的接口；服务端从会话记录解析有效工作区路径，不接受客户端提供任意根目录。
- 每次操作都验证会话存在、执行模式为本机模式，并确认解析后的目标路径仍位于当前工作区根目录内。
- 拒绝路径穿越、根目录外的符号链接逃逸、目录作为文件读取、特殊设备文件及不支持的路径类型；对目录遍历结果做排序和数量上限。
- 读取/保存请求对路径、内容类型和文件大小设上限。保存采用安全写入方式；若文件在读取后被外部修改，返回冲突，要求用户重新加载，避免静默覆盖。
- 不对 HTML、SVG 等可能执行主动内容的格式以内嵌文档方式渲染。文件下载使用安全响应头及附件语义。
- 网页链接不由后端代抓取或代理；前端只在隔离预览上下文加载经校验的 HTTP/HTTPS URL，拒绝 `javascript:`、`data:`、`file:` 等方案，并阻止顶层导航和弹窗。
- 不改变 Agent 工具的文件访问权限，也不把文件面板变成 Agent 文件访问授权机制；面板只呈现当前会话工作区。

## 错误与状态

- 工作区加载失败、目录不可访问、文件被删除/移动、编码不支持、文件过大、保存冲突和权限拒绝均显示可理解的状态与恢复动作。
- 保存失败时保留编辑器内容和未保存状态。
- 关闭/切换时对未保存修改提供保存、放弃、取消选择；保存失败则不丢弃内容。
- 网页禁止嵌入、加载失败或 URL 方案不受支持时显示可理解提示；只有 HTTP/HTTPS 页面可尝试内嵌预览。
- 沙箱模式不尝试读取本机路径，显示解释性空状态。

## 验收与测试

- 聊天页可打开/关闭右侧抽屉，左侧导航不增加文件入口；抽屉展开时占用真实布局宽度、不覆盖聊天或输入区域；窄屏下同样不以覆盖层遮挡内容。
- 聊天顶部不显示设置齿轮，左侧账户区设置按钮保留。
- 消息区域显示独立滚动条；加载/切换会话时默认滚至底部，新消息到达时若用户原本处于底部附近则跟随；向上查看历史时不强制跳回底部。
- 文件树只展示当前会话工作区内容；不同会话/目录切换后不会残留旧目录或打开标签。
- 能打开多个文件/网页标签并切换；聊天里的工作区文件链接可打开对应文件，HTTP/HTTPS 网页链接可打开网页预览。
- 未保存修改在切换/关闭时受到保护；手动保存后内容写回正确文件。
- 支持格式可预览；不支持/主动内容不会在应用内执行，仍可查看文件信息并选择打开/下载。
- 网页预览只接受 HTTP/HTTPS，隔离内容不得操控宿主页面、顶层窗口或本机文件；禁止嵌入的网站有外部浏览器回退入口。
- 沙箱会话不泄露本机文件；没有有效本机工作区时有清晰状态。
- 后端测试覆盖路径穿越、符号链接逃逸、超限文件、并发修改冲突、未知会话及沙箱模式。
- 前端测试覆盖抽屉和标签状态、未保存确认、异步加载时会话切换、文件链接和网页链接，以及失败后编辑内容保留。

## 非目标

- 独立的文件/工作区管理页面或左侧导航入口。
- 在本功能中增加网页搜索、远程云盘或新的外部数据源。
- 让 Docker 沙箱访问或挂载本机工作区。
- 提供完整 IDE 功能（语言服务器、终端、Git 面板等）。
