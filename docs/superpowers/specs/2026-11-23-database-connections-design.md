# 数据库连接与 Agent 授权设计

日期：2026-11-23  
状态：功能方向已确认，待实施

## 目标与范围

工作区侧栏增加独立「数据库」入口（`/databases`），管理本机 SQLite 文件和外部 MySQL 连接。它不是应用内部数据库管理器，也不替代知识库。首版不接 PostgreSQL 等其他数据库，不迁移或复制业务数据。

## 连接管理

- 页面支持添加、编辑、测试连接和删除，可查看连接类型、文件位置或服务器地址，以及最近一次连接测试状态。测试连接只读，不创建文件、库或表。
- SQLite 连接显式选择已有的本机数据库文件；不允许以应用自身的存储数据库作为数据源。MySQL 连接填写主机、端口、库名、用户名和密码；远程连接默认启用证书验证，建议使用数据库侧的最小权限账户。
- SQLite 只保存文件路径；MySQL 保存非秘密连接信息，密码仅保存于系统凭据库。即使是本机请求，列表、测试结果和错误也不返回密码或含密码的 DSN。切换目标或凭据时清除旧测试状态。
- 删除连接只移除应用内的连接配置及关联凭据，不删除源文件或外部数据库。若连接仍被 Agent 引用，返回冲突并显示哪些 Agent 需要先取消授权。
- 备份可包含非秘密连接配置和 Agent 授权；导入时重映射连接 ID，连接未经测试且无密码，不自动连接。本地文件路径在恢复后需重新确认，源数据库内容不纳入应用备份。

## Agent 授权与 SQL 执行

- Agent 配置页可多选已添加的数据库连接，未授权时不展示其工具。运行时在展示及实际执行两个阶段检查授权。调试使用当前草稿选择，并在执行前校验连接仍可用。模型不会获得密码，也不能修改连接配置。
- 每个连接提供「查看结构」「只读查询」与「审批后执行变更」三项能力。将读取和变更区分为不同工具，不按 SQL 的开头猜测权限。变更包括 INSERT、UPDATE、DELETE 和所选引擎支持的 DDL。
- 只读查询由数据库连接本身及语句约束共同保护：SQLite 以只读方式打开并限制非查询操作；MySQL 使用只读事务并限制到批准的查询语句。结构查询使用适配器内置操作。禁止多语句、切换数据库、会话管理、文件操作和其他超出连接授权的语句。不把数据库返回值当成可改变权限的指令。
- 变更工具复用现有审批机制。每次只批准一个明确的目标连接、SQL 和参数组合；拒绝、超时或连接变更后不执行。数据库账户权限不会因批准而提升。审批界面明确显示可能修改或删除数据的操作。
- 所有执行设置超时、最大返回行数及总输出大小限制；结果标记是否截断。连接错误脱敏，运行记录记录连接名、操作类型、状态和耗时，不默认记录 SQL 参数或结果正文。查询结果可能随工具上下文发给所选模型，配置页应对此作出提示。

## 组件与数据

非秘密连接配置和 Agent 授权保存在现有应用 SQLite；SQLite 与 MySQL 分别通过适配器提供测试、结构读取、查询和变更入口。Agent 工具只引用已经登记的连接 ID；连接由后端按需打开并关闭，不接受来自模型的文件路径、主机地址或凭据。管理 API 与 Agent 工具入口分开。

## 验收

- 独立管理本机 SQLite 与 MySQL 连接；用真实 SQLite 和隔离的 MySQL 测试库验证连接、结构与查询。
- Agent 不可查询未授权连接；取消授权后旧的工具调用也不能继续；正在被引用的连接无法删除。
- 只读入口不产生写入；写入、删除、更新及 DDL 仅在当前调用获批并且数据源自身授权时可执行。
- 单语句、超时、行数和字节限制可验证；API、导出及日志不含连接密码。
- 备份恢复正确重映射引用，恢复动作本身不连接外部数据库；未知引用被拒绝。
